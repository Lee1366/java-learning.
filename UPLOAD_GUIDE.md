# Upload homework to GitHub

Use a separate repository named `java-learning` (or `java-homework`). Suggested description: **Java coursework: an object-oriented calculator using inheritance, interfaces and polymorphism.**

1. Download and extract java_homework_github.zip.
2. Open the extracted java-homework folder.
3. In the new repository, choose Add file → Upload files.
4. Drag README.md, UPLOAD_GUIDE.md and the src folder into GitHub. Preserve the nested src folders. Include .gitignore if available in your file picker.
5. Commit with **Add object-oriented calculator homework**.
6. Confirm Main.java is at `src/main/java/org/example/Homework/Main.java`.

Upload the contents inside java-homework, rather than the ZIP itself. Do not add the R scripts to this repository.

This homework replaces the previously suggested list/map starter as the main Java showcase. If that starter was already uploaded, decide whether to remove it or retain it as a separate exercise; its supporting code was partly assistant-created. Do not replace this homework with the older starter ZIP.
